# YouTube Result Optimizer

## Overview
This project leverages a decision tree model to filter YouTube videos, identifying those with the maximum views, likes, and good rating ratios. The repository includes all necessary scripts for data processing, model building, and running the optimization.

## Repository Structure
- `data_process.py`: # Script for cleaning and preprocessing the YouTube data.
- `decision_tree.py`: # Script that implements the decision tree algorithm.
- `model.py`: # Contains functions for training and evaluating the decision tree model.
- `youtube_result_optimization.py`: # Main script that integrates all components to optimize YouTube video selection.


## Project Highlights
- **Decision Tree Filtering**: Filters videos by maximizing views, likes, and rating ratios.
- **Data Processing**: Handles data cleaning and preparation for model input.
